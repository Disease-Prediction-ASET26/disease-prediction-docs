## Documentation ownership

- This repository keeps project, architecture, and model overviews.
- `disease-prediction-infra` keeps Terraform setup and change procedures.
- `disease-prediction-gitops` keeps cluster bootstrap and operations runbooks.
- `disease-prediction-ci` keeps shared workflow use and tool versions.
- Application repositories keep service setup and application-specific CI.

Start with the [cross-repository DevOps overview](devops/README.md) to see
how these parts connect.
